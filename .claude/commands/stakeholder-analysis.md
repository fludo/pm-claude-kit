Produce a **stakeholder analysis**.
PMI Process Group: **Initiating / Planning** · Knowledge Area: **Stakeholder**.

Input: $ARGUMENTS

Use the **stakeholder-analyst** agent. Produce:
- A **register** table: stakeholder | role | interests | concerns | influence | current
  engagement | desired engagement | key message.
- A **power/interest classification**: Manage closely · Keep satisfied · Keep informed ·
  Monitor.
- **Engagement actions** for the highest-priority stakeholders.

If stakeholders aren't listed, infer a candidate set from the project context and label it
as a draft to confirm. Offer to save to `docs/stakeholders.md`.
