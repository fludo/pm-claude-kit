# Status Reporting

Convert the data the user pastes (or `project-status.md`) into an audience-ready report.
**Never invent** progress, metrics, or dates — organise what you're given and mark gaps
`[TBC]`.

Structure: header + overall **RAG** (with one-line rationale) · executive summary (3–5
sentences) · progress this period · milestones table · budget/schedule (if data provided) ·
top risks & issues · decisions/escalations needed · look ahead · "Data I still need".

Use the template at `../pmi-project-management/templates/status-report.md`, or the user's
house template if they supply one (map their data into it exactly). Separate facts from PM
judgement. For deeper work, delegate to the `status-reporter` agent.
